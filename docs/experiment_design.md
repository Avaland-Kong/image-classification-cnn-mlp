# MLP 与 CNN 图像分类对比实验设计书

| 项目 | 内容 |
|------|------|
| 文档版本 | v2.0 |
| 代码仓库 | 本项目根目录 |
| 运行入口 | `main.py` |
| 实验性质 | 对照实验；用于完成可复现的计算机视觉入门项目 |

本文规定实验目的、材料、参数确定流程、正式实验步骤、记录格式与结果汇总方式。执行时以本文及运行产生的 `config.json` 为准。

---

## 1. 实验目的

在统一的数据预处理、损失函数与训练协议下，比较多层感知机（MLP）与卷积神经网络（CNN）在图像分类任务上的测试性能，并考察任务难度变化时二者性能差异的变化情况。

具体包括：

1. 在 MNIST、Fashion-MNIST、CIFAR-10 上分别训练并评估 MLP 与 CNN；
2. 在固定网络结构与训练超参数的前提下，汇总多种子重复实验结果；
3. （可选扩展）检验主结论对训练超参数及网络宽度的敏感性。

## 3. 总体流程

实验按下列阶段顺序执行。进入下一阶段前，须完成本阶段规定产出。

| 阶段 | 名称 | 是否必做 | 产出 |
|------|------|----------|------|
| A | 预实验（先结构，后超参） | 必做 | 第 6 节冻结配置表 |
| B | 主对比实验 | 必做 | 18 次运行日志 + 主结果表 |
| C | 超参数敏感性实验 | 可选 | 补充结果表 |
| D | 网络宽度敏感性实验 | 可选 | 补充结果表 |

约束：

1. 阶段 A 按 A1→A2 完成后，将配置依次写入第 6.1、6.2 节，并作为阶段 B（及阶段 C 的默认结构）的唯一配置来源；
2. 阶段 B 执行过程中不得修改第 6 节已填写内容；
3. 阶段 C、D 的结果不得回写为第 6 节主配置；
4. 阶段 A 不得使用 MNIST、CIFAR-10 的正式测试集指标作为选参依据；主对比的测试指标仅在第 6 节冻结之后用于汇总。

## 4. 通用命名约定

运行名称（`-mn`）须能从字符串还原关键设置。结构标签规则如下：

| 项目 | 规则 |
|------|------|
| 结构标签 `dims_tag` | 将 `-d` 的空格改为连字符；例：`-d 256 128` → `256-128`；`-d 32 64` → `32-64` |
| 种子标签 | `s` + 整数值；例：`s0`，`s42` |

各阶段完整命名格式见对应小节。`config.json` 中的 `dims` 仍为整数列表，须与名称中的 `dims_tag` 一致。

## 5. 阶段 A：预实验

### 5.1 目的

在有限候选范围内，依次确定：

1. 各模型的默认网络结构（对应冻结表第 6.1 节）；
2. 两种模型共用的训练超参数（对应冻结表第 6.2 节）。

使双方在预实验数据上均可稳定训练并达到可接受的学习效果，为阶段 B 提供可复现基线。

### 5.2 顺序原则（与冻结表一致）

预实验严格按 **先结构、后超参** 两步执行，与第 6 节冻结表填写顺序一致：

```text
A1 选定默认网络结构  →  填写冻结表 6.1
A2 选定训练超参数    →  填写冻结表 6.2
```

说明：A1 仅使用一组**临时固定**的训练超参数作为比较载体，该临时设置不等于最终主配置；最终训练协议以 A2 入选结果为准。

### 5.3 条件

| 项目 | 规定 |
|------|------|
| 数据集 | 仅使用 `fashion_mnist` |
| 随机种子 | 允许单一种子，推荐 `42` |
| 模式 | `-mode train_test` |
| 批大小 / 损失 | 128 / CrossEntropy |

### 5.4 候选集合（开始前固定）

**A1 用临时训练超参数（固定，不参与 A1 择优）：**

| 项目 | 取值 |
|------|------|
| 优化器 | `adam` |
| 学习率 | `0.001` |
| 轮次 | `10` |

**网络结构候选（A1 比较对象）：**

| 模型 | 候选 `-d` | 对应 `dims_tag` |
|------|-----------|-----------------|
| MLP | `128 64`；`256 128`；`512 256` | `128-64`；`256-128`；`512-256` |
| CNN | `16 32`；`32 64`；`64 128` | `16-32`；`32-64`；`64-128` |

**训练超参数候选（A2 比较对象；结构已冻结为 A1 入选值）：**

| 编号 | 优化器 `-opt` | 学习率 `-lr` | 轮次 `-e` |
|------|---------------|--------------|-----------|
| T1 | `adam` | `0.001` | `10` |
| T2 | `adam` | `0.0003` | `15` |
| T3 | `sgd` | `0.01` | `15` |

### 5.5 步骤 A1：选定默认网络结构

**操作：**

1. 临时训练超参数固定为第 5.4 节 A1 表；
2. 对 MLP 的每一个结构候选、CNN 的每一个结构候选，分别与对方模型成对无关地完成训练（每种模型各自扫描自己的候选列表）；
3. 同一模型不同结构之间，仅 `-d` / `-mn` 不同，其余参数相同；
4. 按第 5.6 节 A1 准则选出 MLP 默认结构与 CNN 默认结构；
5. **立即填写冻结表第 6.1 节**，其后 A2 不得再改结构。

**A1 命名：**

```text
pre_A1_{model}_d{dims_tag}_s{seed}
```

示例：`pre_A1_mlp_d256-128_s42`，`pre_A1_cnn_d32-64_s42`。

**A1 命令模板：**

```bash
python main.py -mode train_test \
  -m <mlp|cnn> -ds fashion_mnist -d <dims> \
  -opt adam -lr 0.001 -e 10 -s 42 \
  -mn pre_A1_<model>_d<dims_tag>_s42
```

### 5.6 步骤 A1 选定准则

对同一模型的各结构候选：

1. 剔除训练持续发散、异常中断或损失无明显下降的配置；
2. 要求最终训练准确率（`history.csv` 最后一行 `train_acc`）不低于 0.70（Fashion-MNIST）；若调整阈值须记录；
3. 在满足第 2 条的候选中，选择**中等宽度**作为默认结构（MLP 优先 `256 128`，CNN 优先 `32 64`；若该档未达标，则选达标候选中宽度居中者）；
4. 不得以测试集上相对另一模型的领先幅度作为结构入选理由；
5. 未入选的更宽 / 更窄结构保留至阶段 D。

MLP 与 CNN 分别按上述规则独立入选，写入第 6.1 节。

### 5.7 步骤 A2：选定训练超参数

**操作：**

1. `-d` 固定为第 6.1 节已填入选结构；
2. 对 T1、T2、T3，每种超参数下 MLP 与 CNN **成对**运行（相同 `-opt`、`-lr`、`-e`、`-s`）；
3. 按第 5.8 节准则选出一组共用训练超参数；
4. 设定 CIFAR-10 轮次（建议为 Fashion 入选轮次的 1.5～2 倍）；
5. **填写冻结表第 6.2 节**。

**A2 命名：**

```text
pre_A2_{T标签}_{model}_d{dims_tag}_s{seed}
```

其中 `dims_tag` 必须对应第 6.1 节已冻结结构。  
示例：`pre_A2_T1_mlp_d256-128_s42`，`pre_A2_T1_cnn_d32-64_s42`。

**A2 命令模板：**

```bash
python main.py -mode train_test \
  -m <mlp|cnn> -ds fashion_mnist -d <第6.1节对应dims> \
  -opt <T组opt> -lr <T组lr> -e <T组epochs> -s 42 \
  -mn pre_A2_<T标签>_<model>_d<dims_tag>_s42
```

### 5.8 步骤 A2 选定准则

对每一组 T1–T3，在 MLP 与 CNN 均已跑完的前提下：

1. 剔除任一方持续发散、异常中断或损失无明显下降的超参数组；
2. 要求**双方**最终训练准确率均不低于 0.70（与 A1 阈值一致，若曾调整则沿用）；
3. 若多组满足，选择更简配置：优先更少轮次，其次优先 `adam` + `0.001`；
4. 不得以「CNN 测试准确率领先幅度最大」作为超参数入选理由。

CIFAR-10 训练轮次按预先约定比例写入第 6.2 节后，不得再因 CIFAR-10 测试表现更改。

### 5.9 预实验记录

每次运行保留 `logs/<name>/` 全部文件。阶段 A 结束后另存选参说明（如 `docs/pre_experiment_notes.md`），至少包括：

1. A1 实际运行的结构列表与入选结果（对应第 6.1 节）；
2. A2 实际运行的 T 组列表与入选结果（对应第 6.2 节）；
3. 各条入选理由所对应的准则条目。

## 7. 阶段 B：主对比实验

### 7.1 设计说明

| 项目 | 内容 |
|------|------|
| 变化因素 | 数据集 × 模型类型 |
| 固定因素 | 第 6 节网络结构与训练协议 |
| 重复 | 每个「数据集 × 模型」组合使用种子 `0`、`1`、`42` 各一次 |
| 总运行次数 | \(3 \times 2 \times 3 = 18\) |
| 评价方式 | 官方测试集；对 3 次种子结果计算均值与标准差 |

同一对照单元内，MLP 与 CNN 必须使用相同的数据集、优化器、学习率、训练轮次与随机种子；各自使用第 6.1 节对应结构。

### 7.2 运行命名规范

```text
exp1_{dataset}_{model}_d{dims_tag}_s{seed}
```

其中：

- `dataset` ∈ {`mnist`, `fashion_mnist`, `cifar10`}
- `model` ∈ {`mlp`, `cnn`}
- `dims_tag` = 第 6.1 节该模型的结构标签
- `seed` ∈ {`0`, `1`, `42`}

示例：`exp1_mnist_mlp_d256-128_s0`，`exp1_cifar10_cnn_d32-64_s42`。

### 7.3 操作步骤

1. 确认第 6.1 节与第 6.2 节均已填写；
2. 按外层数据集、中层模型、内层种子的顺序执行全部 18 次运行（顺序可调整，但集合必须完整）；
3. 每次运行使用第 7.4 节命令，`-mn` 必须符合第 7.2 节命名，且名称中的 `dims_tag` 与 `-d` 一致；
4. 每次结束后检查：
   - `checkpoints/<name>.pth` 是否生成；
   - `logs/<name>/config.json` 中 `dataset`、`model`、`dims`、`optimizer`、`lr`、`epochs`、`seed` 是否与第 6 节及命名一致；
   - `logs/<name>/history.csv` 行数是否等于训练轮次；
   - `logs/<name>/metrics.json` 是否含 `final_test_loss` 与 `final_test_acc`；
5. 全部完成后，按第 7.5 节汇总主结果表；
6. （建议）绘制测试准确率对比图，以及代表性训练曲线。

### 7.4 命令模板

将尖括号内容替换为第 6 节冻结值。

```bash
python main.py -mode train_test \
  -m mlp -ds <dataset> -d <第6.1节MLP的d> \
  -opt <第6.2节opt> -lr <第6.2节lr> -e <对应数据集的epochs> \
  -s <seed> -mn exp1_<dataset>_mlp_d<MLP的dims_tag>_s<seed>

python main.py -mode train_test \
  -m cnn -ds <dataset> -d <第6.1节CNN的d> \
  -opt <第6.2节opt> -lr <第6.2节lr> -e <对应数据集的epochs> \
  -s <seed> -mn exp1_<dataset>_cnn_d<CNN的dims_tag>_s<seed>
```

完整展开时，对每个 `dataset`、每个 `seed` 各执行上述两条命令，共 18 次。

对每个「数据集 × 模型」，读取三次运行的 `final_test_acc`，计算算术平均与样本标准差，填入下表。差值列定义为：CNN 均值 − MLP 均值。

| 数据集 | MLP Acc (mean±std) | CNN Acc (mean±std) | 差值 (CNN−MLP) |
|--------|--------------------|--------------------|----------------|
| MNIST | | | |
| Fashion-MNIST | | | |
| CIFAR-10 | | | |

可选附表：对应的测试损失 mean±std。

### 7.6 结果说明要求

依据第 7.5 节表格描述：

1. 各数据集上两种模型测试准确率的相对高低；
2. 随数据集难度变化，差值列的变化趋势；
3. 多种子标准差所反映的结果波动情况。

说明须与表格数据一致；若与常见经验不符，应讨论可能原因（容量、训练轮次、优化过程等），不得为符合预期叙述而重新选择主配置并替换本表。

## 8. 阶段 C：超参数敏感性实验（可选）

### 8.1 目的

在第 6.1 节默认结构保持不变的前提下，更换有限组训练超参数，观察阶段 B 的定性结论是否仍然成立。

### 8.2 设计

| 项目 | 规定 |
|------|------|
| 数据集 | 固定为 `fashion_mnist` 或 `cifar10`（执行前选定并记录） |
| 结构 | 使用第 6.1 节 |
| 超参数组 | 预先列出 2～3 组，须与第 6.2 节主配置不同；推荐从第 5.4 节未入选的 T 组中选取 |
| 模型 | 每组均运行 MLP 与 CNN |
| 种子 | 优先 `0, 1, 42`；若资源不足，至少使用与阶段 B 相同的单一种子，并在结果中注明 |

### 8.3 命名与命令

```text
exp2_{dataset}_{model}_d{dims_tag}_{tag}_s{seed}
```

`dims_tag` 取第 6.1 节对应模型的结构标签。

```bash

```

## 9. 阶段 D：网络宽度敏感性实验（可选）

### 9.1 目的

在第 6.2 节训练协议保持不变的前提下，更换网络宽度，观察阶段 B 的定性结论是否依赖于默认宽度设定。

### 9.2 设计

| 项目 | 规定 |
|------|------|
| 数据集 | 固定为与阶段 C 相同或另行声明的单一数据集 |
| 训练协议 | 使用第 6.2 节 |
| 宽度集合 | 从第 5.4 节结构候选中预先声明子集 |
| 种子 | 同阶段 C |

### 9.3 命名与命令

```text
exp3_{dataset}_{model}_d{dims_tag}_s{seed}
```

此处 `dims_tag` 为**本组实际使用的宽度**（可与第 6.1 节默认结构不同）。

```bash
python main.py -mode train_test \
  -m <model> -ds <dataset> -d <本组dims> \
  -opt <第6.2节opt> -lr <第6.2节lr> -e <对应epochs> \
  -s <seed> -mn exp3_<dataset>_<model>_d<dims_tag>_s<seed>
```

## 10. 随机性与统计汇总

| 规则 | 说明 |
|------|------|
| 种子固定方法 | `main.py` 中 `set_seed`，并为 `DataLoader` 设置 `generator` |
| 组间公平 | 同一对照条件下两种模型使用同一 `-s` |
| 阶段 B 汇总 | 对每个单元格的 3 个 `final_test_acc` 计算 mean 与 sample std |
| 阶段 A | 允许单一种子 |

均值与标准差计算公式（对数值 \(x_1,x_2,x_3\)）：

\[
\bar{x}=\frac{1}{3}\sum_{i=1}^{3}x_i,\quad
s=\sqrt{\frac{1}{2}\sum_{i=1}^{3}(x_i-\bar{x})^2}
\]

（样本标准差，分母为 \(n-1=2\)。）
