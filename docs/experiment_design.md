# MLP 与 CNN 图像分类对比实验设计书


| 项目   | 内容                     |
| ---- | ---------------------- |
| 文档版本 | v2.4                   |
| 代码仓库 | 本项目根目录                 |
| 运行入口 | `main.py`              |
| 实验性质 | 对照实验；用于完成可复现的计算机视觉入门项目 |


本文规定实验目的、材料、参数确定流程、正式实验步骤、记录格式与结果汇总方式。执行时以本文及运行产生的 `config.json` 为准。

---

## 1. 实验目的

在统一的数据预处理、损失函数与训练协议下，比较多层感知机（MLP）与卷积神经网络（CNN）在图像分类任务上的测试性能，并考察任务难度变化时二者性能差异的变化情况。

具体包括：

1. 在 MNIST、Fashion-MNIST、CIFAR-10 上分别训练并评估 MLP 与 CNN；
2. 在固定网络结构与训练超参数的前提下，汇总多种子重复实验结果；
3. （可选扩展）检验主结论对训练超参数及网络宽度的敏感性。

## 2. 实验材料与环境

### 2.1 软件与代码


| 项目      | 说明                              |
| ------- | ------------------------------- |
| 语言 / 框架 | Python，PyTorch，torchvision      |
| 数据加载    | `dataset_config.get_datasets`   |
| 模型定义    | `models/mlp.py`，`models/cnn.py` |
| 训练 / 测试 | `train.py`，`test.py`            |
| 命令行入口   | `main.py`                       |


### 2.2 数据集


| 名称            | 命令参数 `-ds`      | 输入尺寸    | 类别数 | 官方划分      |
| ------------- | --------------- | ------- | --- | --------- |
| MNIST         | `mnist`         | 1×28×28 | 10  | 训练集 / 测试集 |
| Fashion-MNIST | `fashion_mnist` | 1×28×28 | 10  | 训练集 / 测试集 |
| CIFAR-10      | `cifar10`       | 3×32×32 | 10  | 训练集 / 测试集 |


预处理：`transforms.ToTensor()`，再按各数据集预设均值与方差做 `Normalize`（实现见 `dataset_config.py`）。数据下载至项目 `data/<dataset>/`（如 `data/mnist/`、`data/fashion_mnist/`、`data/cifar10/`）。

三个数据集按视觉任务复杂度递增排列，排序依据为通道数、背景复杂度与类内差异等数据固有属性。

### 2.2.1 训练 / 验证 / 测试划分

官方训练集按比例再划分为 **训练子集** 与 **验证集**；官方测试集保持不变，仅用于阶段 B（及可选 C/D）的最终评估。


| 项目         | 规定                                        |
| ---------- | ----------------------------------------- |
| 验证集比例      | 默认 `val_ratio=0.1`（命令行 `-vr`）             |
| 划分方式       | 对官方 `train=True` 子集做 `random_split`       |
| 划分种子       | 与运行种子 `-s` 相同，保证可复现                       |
| 选参依据（阶段 A） | 验证集 `val_acc` / `val_loss`（`history.csv`） |
| 最终评价（阶段 B） | 官方测试集 `final_test_acc`                    |


每个训练 epoch 结束后额外在验证集上评估一次，写入 `history.csv` 的 `val_loss`、`val_acc`，供选参与绘图。

**预实验仅使用 MNIST**；Fashion-MNIST 与 CIFAR-10 仅出现在正式主对比及可选扩展中。

### 2.3 模型


| 模型  | 命令参数 `-m` | 结构参数 `-d` |
| --- | --------- | --------- |
| MLP | `mlp`     | 各隐藏层宽度    |
| CNN | `cnn`     | 各卷积层输出通道数 |


输入形状与类别数由当前数据集自动确定。损失函数固定为交叉熵（`cross_entropy` / `nn.CrossEntropyLoss`）。批大小固定为 128。

## 3. 总体流程

实验按下列阶段顺序执行。进入下一阶段前，须完成本阶段规定产出。


| 阶段  | 名称                 | 是否必做 | 产出              |
| --- | ------------------ | ---- | --------------- |
| A   | 预实验（定结构与协议；不做模型对比） | 必做   | 第 6 节冻结配置表      |
| B   | 主对比实验              | 必做   | 18 次运行日志 + 主结果表 |
| C   | 超参数敏感性实验           | 可选   | 补充结果表           |
| D   | 网络宽度敏感性实验          | 可选   | 补充结果表           |


约束：

1. 阶段 A 按 **A1→A2→A3** 完成后，将配置写入第 6.1、6.2 节，并作为阶段 B 的唯一配置来源；
2. 阶段 B 执行过程中不得修改第 6 节已填写内容；
3. 阶段 C、D 的结果不得回写为第 6 节主配置；
4. 预实验仅使用 MNIST；仅依据训练稳定性与**验证集**指标选参；**不跑测试集、不以测试指标选参**；**不以两模型谁更高为选参标准**；主对比测试指标仅在第 6 节冻结之后用于汇总。全流程默认启用验证集（`-vr 0.1`）。

阶段 A 与阶段 B 的区别：A 用于确定「训什么结构、用什么超参」（只训练）；B 才进行 MLP 与 CNN 的对照评价（训练并在测试集上评估）。

## 4. 通用命名约定

运行名称（`-mn`）须能从字符串还原关键设置。结构标签规则如下：


| 项目              | 规则                                                              |
| --------------- | --------------------------------------------------------------- |
| 结构标签 `dims_tag` | 将 `-d` 的空格改为连字符；例：`-d 256 128` → `256-128`；`-d 32 64` → `32-64` |
| 种子标签            | `s` + 整数值；例：`s17`，`s32`，`s61`                                  |


各阶段完整命名格式见对应小节。`config.json` 中的 `dims` 仍为整数列表，须与名称中的 `dims_tag` 一致。

## 5. 阶段 A：预实验

### 5.1 目的

确定主实验的默认网络结构与共用训练超参数，使训练过程稳定、可复现。

本阶段**不是**模型对比实验：不比较 MLP 与 CNN 的优劣，也不以二者测试差距为选参目标。

### 5.2 顺序原则（与冻结表一致）

```text
A1 各自选定 MLP / CNN 默认结构     →  填写 6.1
A2 仅用 MLP 选定训练超参数         →  填写 6.2
A3 用 CNN 按 6.1 / 6.2 验证一次    →  通过后正式冻结
```

说明：

- A1 使用临时固定超参数，仅作结构筛选载体；
- A2 **只训练 MLP**，得到两模型在主实验中共用的训练协议；
- A3 **不重新选参**，只确认该协议在 CNN 上可正常训练。

全流程默认 `-vr 0.1`；命令中可显式写出。因数据划分变更，此前不含验证集的运行结果须全部重跑。

### 5.3 条件


| 项目       | 规定                                                       |
| -------- | -------------------------------------------------------- |
| 数据集      | 仅使用 `mnist`                                              |
| 随机种子     | 允许单一种子，推荐 `42`                                           |
| 模式       | `-mode train`（只训练，不评估测试集；不生成以测试结果为依据的选参）                 |
| 批大小 / 损失 | 128 / CrossEntropy                                       |
| 验证集      | 默认 `-vr 0.1`，与主实验相同                                      |
| 选参阈值（默认） | 最终 `val_acc` **≥ 0.90**（来自 `history.csv`）；若调整须记录         |
| 产物       | `history.csv`（含 train/val）、`config.json`；预实验**不使用**测试集指标 |


### 5.4 候选集合（开始前固定）

**A1 临时训练超参数（固定，不参与 A1 择优）：**


| 项目  | 取值      |
| --- | ------- |
| 优化器 | `adam`  |
| 学习率 | `0.001` |
| 轮次  | `10`    |


**网络结构候选（A1；两模型各自扫描，互不做性能对比）：**


| 模型  | 候选 `-d`                      | 对应 `dims_tag`                |
| --- | ---------------------------- | ---------------------------- |
| MLP | `128 64`；`256 128`；`512 256` | `128-64`；`256-128`；`512-256` |
| CNN | `16 32`；`32 64`；`64 128`     | `16-32`；`32-64`；`64-128`     |


**训练超参数候选（A2；仅 MLP、结构固定为第 6.1 节入选值）：**

共 **6** 组，覆盖 Adam / SGD 的常用学习率与轮次组合：


| 编号  | 优化器 `-opt` | 学习率 `-lr` | 轮次 `-e` | 说明              |
| --- | ---------- | --------- | ------- | --------------- |
| T1  | `adam`     | `0.001`   | `5`     | Adam 默认 lr，短训   |
| T2  | `adam`     | `0.001`   | `10`    | Adam 默认 lr，中等轮次 |
| T3  | `adam`     | `0.0003`  | `15`    | 更小 lr + 更长轮次    |
| T4  | `adam`     | `0.003`   | `10`    | 更大 lr（检验稳定性）    |
| T5  | `sgd`      | `0.01`    | `10`    | SGD 常用起点        |
| T6  | `sgd`      | `0.05`    | `15`    | SGD 更大 lr + 稍长训 |


结构固定：`-m mlp -d 256 128`（与第 6.1 节一致）。  
选参仍按第 5.8 节：先看是否达标与稳定，再在达标组中取更简配置；不以测试集、不以相对 CNN 的差距为标准。

### 5.5 步骤 A1：选定默认网络结构

**性质：** 为每个模型单独选定默认宽度；不比较 MLP 与 CNN 谁更高。

**操作：**

1. 临时超参数固定为第 5.4 节 A1 表；
2. 对 MLP 各结构候选各训练一次；对 CNN 各结构候选各训练一次；
3. 同一模型不同结构之间，仅 `-d` / `-mn` 不同；
4. 按第 5.6 节准则分别选出 MLP、CNN 默认结构；
5. **填写冻结表第 6.1 节**。

**命名：**

```text
pre_A1_{model}_d{dims_tag}_s{seed}
```

示例：`pre_A1_mlp_d256-128_s42`，`pre_A1_cnn_d32-64_s42`。

**命令模板：**

```bash
python main.py -mode train \
  -m <mlp|cnn> -ds mnist -d <dims> \
  -opt adam -lr 0.001 -e 10 -s 42 -vr 0.1 \
  -mn pre_A1_<model>_d<dims_tag>_s42
```

### 5.6 步骤 A1 选定准则

对同一模型的各结构候选独立判断：

1. 剔除持续发散、异常中断或损失无明显下降的配置；
2. 最终 `val_acc`（`history.csv` 最后一行）不低于第 5.3 节阈值；
3. 在达标候选中选中等宽度（MLP 优先 `256 128`，CNN 优先 `32 64`；该档未达标则选达标者中宽度居中者）；
4. 不得使用测试集指标；不得以相对另一模型的表现为入选理由；
5. 未入选宽度可留至阶段 D。

### 5.7 步骤 A2：选定训练超参数（仅 MLP）

**性质：** 只在 MLP 上比较 T1–T6；本步不训练 CNN，不做模型对比；不跑测试集。

**操作：**

1. `-m mlp`，`-d` 固定为第 6.1 节 MLP 结构（`256 128`）；
2. 对 T1–T6 各训练一次（`-mode train`，`-vr 0.1`）；
3. 按第 5.8 节准则选出一组超参数；
4. 设定主实验中 Fashion-MNIST 轮次（可与 MNIST 入选轮次相同）及 CIFAR-10 轮次（建议为 MNIST 入选轮次的 1.5～2 倍）；
5. **填写冻结表第 6.2 节**（A3 通过后正式冻结）。

**命名：**

```text
pre_A2_{T标签}_mlp_d{dims_tag}_s{seed}
```

示例：`pre_A2_T1_mlp_d256-128_s42`。

**命令模板：**

```bash
python main.py -mode train \
  -m mlp -ds mnist -d <第6.1节MLP的d> \
  -opt <T组opt> -lr <T组lr> -e <T组epochs> -s 42 -vr 0.1 \
  -mn pre_A2_<T标签>_mlp_d<MLP的dims_tag>_s42
```

### 5.8 步骤 A2 选定准则

仅根据 MLP 的训练日志判断：

1. 剔除发散、中断或损失无明显下降的 T 组；
2. MLP 最终 `val_acc` 不低于第 5.3 节阈值；
3. 多组达标时选更简配置：优先更少轮次，其次优先 `adam` + `0.001`；
4. 不得引入 CNN 结果，不得使用测试集指标参与选择。

### 5.9 步骤 A3：CNN 接通验证

**性质：** 超参已由 MLP 选定后，用 CNN 按第 6.1 / 6.2 节各跑 **一次**（仍为 `-mode train`），确认协议可迁移。不重新选参，不与 MLP 比分，不跑测试集。

**操作：**

1. `-m cnn`，`-d` 取第 6.1 节 CNN 结构；
2. `-opt` / `-lr` / `-e` 取第 6.2 节中 MNIST 档取值；
3. 种子与 A2 相同（推荐 `42`）；
4. 按第 5.10 节判断是否通过；
5. 通过后，在冻结表元信息中记录 A3 已通过，第 6 节正式冻结，进入阶段 B。

**命名：**

```text
pre_A3_cnn_d{dims_tag}_s{seed}
```

示例：`pre_A3_cnn_d32-64_s42`。

**命令模板：**

```bash
python main.py -mode train \
  -m cnn -ds mnist -d <第6.1节CNN的d> \
  -opt <第6.2节opt> -lr <第6.2节lr> -e <第6.2节MNIST轮次> -s 42 -vr 0.1 \
  -mn pre_A3_cnn_d<CNN的dims_tag>_s42
```

### 5.10 步骤 A3 通过准则与失败处理

**通过：** 训练稳定（损失总体下降、无持续发散），且最终 `val_acc` 不低于第 5.3 节阈值。

**未通过时（仍不做模型对比、仍不依据测试集）：**

1. 在 A2 已达标的 T 组中，按第 5.8 节「更简优先」取下一组，更新第 6.2 节后重跑 A3 一次；
2. 若仍未通过，可将 MNIST / Fashion 轮次按预先声明幅度上调（例如 +5），更新第 6.2 节后再验证一次；
3. 过程写入选参说明；不得根据测试集表现或「相对 MLP 高低」调整配置。

### 5.11 预实验记录

保留全部 `logs/<name>/`（至少含 train/val 字段的 `history.csv`、`config.json`）。另存选参说明（如 `docs/pre_experiment_notes.md`），至少包括：

1. A1 各模型结构候选与入选结果（第 6.1 节）；
2. A2 仅 MLP 的 T 组列表与入选超参（第 6.2 节）；
3. A3 CNN 验证是否通过及失败处理（若有）；
4. 声明：预实验未评估测试集、未进行两模型性能对比；超参由 MLP 选定后两模型共用。

## 7. 阶段 B：主对比实验

### 7.1 设计说明


| 项目    | 内容                                  |
| ----- | ----------------------------------- |
| 变化因素  | 数据集 × 模型类型                          |
| 固定因素  | 第 6 节网络结构与训练协议                      |
| 重复    | 每个「数据集 × 模型」组合使用种子 `17`、`32`、`61` 各一次 |
| 总运行次数 | 3 \times 2 \times 3 = 18            |
| 评价方式  | 官方测试集；对 3 次种子结果计算均值与标准差             |


同一对照单元内，MLP 与 CNN 必须使用相同的数据集、优化器、学习率、训练轮次与随机种子；各自使用第 6.1 节对应结构。本阶段才是两模型性能对比。

### 7.2 运行命名规范


## 10. 随机性与统计汇总


| 规则         | 说明                                                    |
| ---------- | ----------------------------------------------------- |
| 种子固定方法     | `main.py` 中 `set_seed`，并为 `DataLoader` 设置 `generator` |
| 组间公平（阶段 B） | 同一对照条件下两模型使用同一 `-s`                                   |
| 阶段 B 汇总    | 3 个种子的 mean 与 sample std                              |
| 阶段 A       | 允许单一种子                                                |


\bar{x}=\frac{1}{3}\sum_{i=1}^{3}x_i,\quad
s=\sqrt{\frac{1}{2}\sum_{i=1}^{3}(x_i-\bar{x})^2}
