# 预实验 A1：默认网络结构筛选

| 项目 | 内容 |
|------|------|
| 阶段 | 预实验 A1 |
| 日期 | 2026-08-30 |
| 数据集 | `mnist` |
| 划分 | train/val/test = 54000/6000/10000（`val_ratio=0.1`，种子与运行一致） |
| 模式 | `-mode train`（不评估测试集） |
| 临时超参 | Adam，`lr=0.001`，`epochs=10`，`seed=42`，`-vr 0.1` |
| 环境 | `image-cls`；PyTorch 2.5.1+cu121；GPU RTX 4060 Laptop |
| 总耗时 | 约 6.3 分钟（六组） |

选参依据：最终 epoch 的 **`val_acc`**（阈值 ≥ 0.90）。本阶段不做 MLP 与 CNN 的性能对比。

---

## 1. MLP 结构候选

命令模板：

```bash
python main.py -mode train -m mlp -ds mnist -d <dims> \
  -opt adam -lr 0.001 -e 10 -s 42 -vr 0.1 \
  -mn pre_A1_mlp_d<dims_tag>_s42
```

| 运行名 | `-d` | 最终 train_loss | 最终 train_acc | 最终 val_loss | 最终 **val_acc** | 达标 |
|--------|------|-----------------|----------------|---------------|------------------|------|
| `pre_A1_mlp_d128-64_s42` | `128 64` | 0.0241 | 0.9923 | 0.0983 | **0.9742** | 是 |
| `pre_A1_mlp_d256-128_s42` | `256 128` | 0.0162 | 0.9948 | 0.0904 | **0.9792** | 是 |
| `pre_A1_mlp_d512-256_s42` | `512 256` | 0.0203 | 0.9929 | 0.0973 | **0.9765** | 是 |

日志目录：`logs/pre_A1_mlp_d*_s42/`（含 `history.csv`、`config.json`）。

---

## 2. CNN 结构候选

命令模板：

```bash
python main.py -mode train -m cnn -ds mnist -d <dims> \
  -opt adam -lr 0.001 -e 10 -s 42 -vr 0.1 \
  -mn pre_A1_cnn_d<dims_tag>_s42
```

| 运行名 | `-d` | 最终 train_loss | 最终 train_acc | 最终 val_loss | 最终 **val_acc** | 达标 |
|--------|------|-----------------|----------------|---------------|------------------|------|
| `pre_A1_cnn_d16-32_s42` | `16 32` | 0.0112 | 0.9960 | 0.0413 | **0.9878** | 是 |
| `pre_A1_cnn_d32-64_s42` | `32 64` | 0.0117 | 0.9958 | 0.0399 | **0.9905** | 是 |
| `pre_A1_cnn_d64-128_s42` | `64 128` | 0.0106 | 0.9963 | 0.0475 | **0.9877** | 是 |

日志目录：`logs/pre_A1_cnn_d*_s42/`。

---

## 3. 入选结构

按实验设计：多档达标时优先中等宽度；本组中等档同时具有最高 `val_acc`。

| 模型 | 入选 `-d` | `dims_tag` | 入选理由 |
|------|-----------|------------|----------|
| MLP | `256 128` | `256-128` | 达标候选中的中等宽度；本组最终 val_acc 最高（0.9792） |
| CNN | `32 64` | `32-64` | 达标候选中的中等宽度；本组最终 val_acc 最高（0.9905） |
