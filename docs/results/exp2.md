# 阶段 C：超参数敏感性实验（CIFAR-10）

| 项目 | 内容 |
|------|------|
| 阶段 | 超参数敏感性（阶段 C） |
| 日期 | 2026-09-03 |
| 模式 | `-mode train_test`（训练后在官方测试集评估） |
| 结构 | 第 6.1 节：MLP `-d 256 128`；CNN `-d 32 64`（不变） |
| 数据集 | 仅 `cifar10`（划分 45000 / 5000 / 10000，`-vr 0.1`） |
| 超参数组 | `T1s`、`T3s`、`T4s`、`T6s`（见设计书第 8.2 节） |
| 种子 | `17`，`32`，`61` |
| 运行次数 | 24 |
| 基线对照 | 阶段 B 的 CIFAR-10（B0：Adam，`lr=0.001`，`-e 20`），不重跑 |
| 环境 | `image-cls`；PyTorch 2.5.1+cu121；GPU RTX 4060 Laptop |
| 总耗时 | 约 71.5 分钟（24 次合计） |

评价依据：官方测试集 **`final_test_acc`**（`metrics.json`）。mean 与 sample std 按三个种子计算（设计书第 10 节）。

定性结论「仍成立」= 该组 CNN 测试准确率均值仍明显高于 MLP（差值符号与阶段 B 相同，且幅度远大于多种子波动）。

命令模板：

```bash
python main.py -mode train_test \
  -m mlp -ds cifar10 -d 256 128 \
  -opt <opt> -lr <lr> -e <epochs> -s <seed> -vr 0.1 \
  -mn exp2_cifar10_mlp_d256-128_<tag>_s<seed>

python main.py -mode train_test \
  -m cnn -ds cifar10 -d 32 64 \
  -opt <opt> -lr <lr> -e <epochs> -s <seed> -vr 0.1 \
  -mn exp2_cifar10_cnn_d32-64_<tag>_s<seed>
```

## 3. 简要观察

- **四组均与阶段 B 定性一致**：CNN 测试准确率始终明显高于 MLP，差值约 19.8～25.2 个百分点，远大于多种子波动（std 约 0.001～0.012）。主结论不依赖 Adam `lr=0.001`、20 epoch 这一组具体超参。
- **T1s（早停 10 epoch）**：MLP 测试准确率略高于 B0（0.522 vs 0.509），CNN 与 B0 几乎相同（0.721）；train−val 差距明显缩小（MLP 0.16 vs B0 0.32；CNN 0.12 vs B0 0.22）。说明阶段 B 在 20 轮中后段的过拟合主要拉低了 MLP，缩短训练可减轻过拟合，但 **CNN−MLP 差距仍约 20 个百分点**。
- **T3s（更小 lr、30 epoch）**：测试准确率接近 B0，但最终过拟合更重（MLP train_acc 约 0.91、test 约 0.52）。小步长拉长训练并不能消除 CIFAR-10 上的过拟合，也未改变差距方向。
- **T4s（更大 lr）**：两模型测试准确率都略降（MLP 0.497、CNN 0.707），差值仍为 0.210，与 B0 几乎相同。大学习率略伤性能，但不翻转结论。
- **T6s（SGD）**：MLP 与 B0 接近或略差（0.498）；CNN 升至 0.751，差值扩大到 0.252。CNN 训练集准确率接近 1.0，过拟合仍在，但测试端对 SGD 更受益。结论「CNN 明显优于 MLP」在换优化器后仍然成立，且差距未缩小。
- 绝对准确率随超参有升降，均不回写第 6 节冻结配置。
