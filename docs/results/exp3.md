# 阶段 D：结构敏感性实验（CIFAR-10，两层、参数量对齐）

| 项目 | 内容 |
|------|------|
| 阶段 | 结构敏感性（阶段 D） |
| 日期 | 2026-09-03 |
| 模式 | `-mode train_test`（训练后在官方测试集评估） |
| 训练协议 | 第 6.2 节：Adam，`lr=0.001`，`-e 20`，`-vr 0.1` |
| 数据集 | 仅 `cifar10`（划分 45000 / 5000 / 10000） |
| 结构组 | 三组两层：`L2n`、`L2m`、`L2w`（参数量依次增加；组内 MLP/CNN 相对误差 < 0.2%） |
| 种子 | `17`，`32`，`61` |
| 运行次数 | 18 |
| 基线对照 | 阶段 B 的 CIFAR-10（容量未对齐）；不重跑 |
| 环境 | `image-cls`；PyTorch 2.5.1+cu121；GPU RTX 4060 Laptop |
| 总耗时 | 约 40 分钟（18 次合计） |

评价依据：官方测试集 **`final_test_acc`**（`metrics.json`）。mean 与 sample std 按三个种子计算（设计书第 10 节）。

固定两层：本实现中 CNN 每多一个通道层就多一次池化，分类头缩小，MLP 无此机制；深度会与容量缠在一起，故本阶段只扫宽度。

定性结论「仍成立」= 该宽度组上 CNN 测试准确率均值仍明显高于 MLP。

训练前用 `sum(p.numel())` 核对参数量，与设计书第 9.2 节一致。

命令模板：

```bash
python main.py -mode train_test \
  -m <mlp|cnn> -ds cifar10 -d <本组dims> \
  -opt adam -lr 0.001 -e 20 -s <seed> -vr 0.1 \
  -mn exp3_cifar10_<model>_d<dims_tag>_<tag>_s<seed>
```

## 3. 简要观察

- **三组均与阶段 B 定性一致**：固定两层、组内参数量对齐后，CNN 测试准确率仍明显高于 MLP，差值约 19.3～22.4 个百分点。
- **容量差不是主因。** `L2m` 把 MLP 从阶段 B 的 821k 收到与 CNN 相同的 545k，MLP 仍约 0.505（B0 为 0.509），差值 0.215 与 B0 的 0.211 几乎相同。
- **加宽对 CNN 更有用。** 随 N 增加（269k → 545k → 1.13M），CNN：0.698 → 0.720 → 0.741；MLP：0.505 → 0.505 → 0.516。差值略扩大（0.193 → 0.215 → 0.224），没有出现 MLP 追上 CNN 的迹象。
- 更宽的 MLP 训练集准确率升到约 0.86，但测试只到约 0.52，过拟合加重（测试损失也升到 2.33）。绝对准确率升降不回写第 6 节。
